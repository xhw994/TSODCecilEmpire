# 塞西尔帝国：美术补全后的实机测试清单（10-25）

这一批只动了美术和百科的一个 UI 脚本，**玩法一行没改**。下面按「最少操作验最多东西」排序。每一项都标了怎么到达那个画面、看什么、不对时是什么意思。测完告诉我一声，日志我自己读，不用你贴。

规则集用《风云变幻》（依赖迭起兴衰、越南和忽必烈包、埃塞俄比亚包），和以前一样。

## 一、改了什么（本批 9 个本地提交，没推送）

| 方面 | 改动 |
|---|---|
| 高文立绘 | 外交画面和载入画面原来是 39×39 空图，现在有图；外交画面换成坐姿高文加太空星球背景；选领袖界面立绘裁近了一点 |
| 贴图包改名 | 5 个包都加了 `TsoDCE_` 前缀（原名 `UILeaders`、`LeaderFallbacks` 等太通用，可能和别的 mod 撞名），Art.xml、两个 artdef、工程文件同步 |
| 清理 | 删 2 个重复的忠诚度资产、8 个旧领袖图标、10 个空文件夹、旧的 `Cooked/`（在回收站） |
| 图标 | 琥珀 7 个晋升全换成自己的盾形图标；2 部巨作换成海报图标；魔力方尖碑、琥珀、戈尔贡平台补了战争迷雾版 |
| 百科 | 伟人页按个人显示肖像：6 位有肖像，其余 6 位等你出图，没图时照旧显示伟人单位图标 |

| 工具 | `tools/make_art.py`（所有派生贴图都由它生成）、`tools/restore_cooked_entries.py`（换成提丰的新版，构建后自动还原被清空的引用） |

构建结果：`--clean` 重建通过，artdef 里 0 个 `TB_ERROR`、0 个被清空的引用，`validate_mod`、Lua 检查 0 错误；`loc_audit` 报的 3 项是 SQL 拼接出来的名字前缀，拼完都有定义。

## 二、第一档：开游戏就能看到（约 5 分钟）

不用开局，在主菜单到开局设置到载入画面里就能看。

| # | 到达方式 | 看什么 | 不对时 |
|---|---|---|---|
| 1 | 单人游戏，高级设置，领袖选高文·塞西尔 | 左侧立绘是穿铠甲、扛着发光大剑的高文，头在画面偏上，没有被切；文明 / 领袖图标都在 | 立绘空白或很小：看 `Modding.log` 里 `TsoDCE_UILeaders` |
| 2 | 点开始，看载入画面 | 左侧出现高文立绘（以前是空的），右边是众人合影背景 | 空白：同上 |
| 3 | 进游戏后看左上角的领袖头像、城市旗帜 | 文明图标、领袖图标都正常，没有变成问号 | 图标变空：包名改名漏了某个引用 |
